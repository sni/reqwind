# Changelog

## v0.0.1 - 2026-11-16

### Added

- Apache and nginx access-log analysis with static HTML reports.
- Incremental reads, gzip input, live polling, and saved-state merging.
- Reports by year, month, and virtual host.
- Offline geolocation and optional client-address hashing.
- GitHub Actions checks for tests, formatting, lint, and vulnerabilities.
- Linux x86-64 (`amd64`) and ARM64 (`arm64`) binary archives.
- Draft GitHub releases for `v*` tags, with manual publishing.
- Dependabot update checks for GitHub Actions and Go modules.
